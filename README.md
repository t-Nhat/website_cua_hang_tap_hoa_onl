# Website Cửa Hàng Tạp Hóa Online (website_cua_hang_tap_hoa_onl)

Dự án website bán hàng trực tuyến cho cửa hàng tạp hóa.

## Danh sách nhánh (Branches)
- main: Nhánh chính (Production)
- 	est: Nhánh kiểm thử (Testing/Staging)
- Nhat: Nhánh phát triển của Nhật
- Phat: Nhánh phát triển của Phát
- Quoc: Nhánh phát triển của Quốc
